# Андрей Генрих — адвокат в Тюмени

Одностраничный лендинг для адвоката **Генриха Андрея Витальевича**
(реестровый номер **72/1306**, Адвокатская палата Тюменской области).

Оформление продолжает редакционную серию прошлых лендингов: тёмная тема,
крупная антиква, нумерованные секции, технические схемы и один латунный акцент.
Портрет вписан в арочную раму, реестровый номер вынесен в отдельный знак.

## Что внутри

```
advokat-genrih/
├── index.html          — разметка, SVG-спрайт (иконки, схемы, знак)
├── css/style.css       — стили, адаптив, анимации
├── js/main.js          — меню, появление блоков, лайтбокс, FAQ, форма
├── assets/
│   ├── portrait.jpg    — портрет, кадрирован 4:5 и подготовлен для сайта
│   └── favicon.svg     — знак «весы» для вкладки
├── preview.png         — первый экран
└── README.md
```

## Важно перед публикацией

- Портрет предоставлен заказчиком. Исходник кадрирован по центру до 4:5
  (512×640 → 880×1100), без дорисовки фона.
- **Телефоны и адрес — публичные контакты ТМКА**, а не подтверждённый личный
  номер адвоката: +7 (919) 939-18-17, +7 (3452) 520-636,
  notmka72@mail.ru, г. Тюмень, ул. 30 лет Победы, 14/1А. Замените на прямые
  контакты приёмной, если они отличаются.
- Цены не выдуманы: в блоках «Форматы работы» указано «по соглашению».
  Гонорар фиксируется в соглашении об оказании юридической помощи.
- Отзывов нет — вместо них блок «Принципы», чтобы не придумывать клиентские
  цитаты. Дела взяты из открытых публикаций; внизу есть оговорка, что прошлый
  результат не гарантирует исход нового дела.
- В `<head>` стоит `<meta name="robots" content="noindex,nofollow">` — это
  демонстрационная версия. Удалите строку перед публикацией.
- Форма проверяет имя, телефон и согласие, но **бэкенда нет**: успех показывается
  на клиенте. Подключите API, Telegram-бот или почтовый сервис в блоке
  `/* форма */` в `js/main.js` либо добавьте `action`/`method` в `<form>`.
- Стаж «9 лет» и год в подвале рассчитаны на 2026 год. Обновите цифру или
  сделайте её вычисляемой, если сайт будет жить дольше.
- Ссылка на профиль в реестре ведёт на страницу 8 списка ТМКА. При изменении
  пагинации её нужно обновить (либо заменить на карточку в реестре Минюста).

## Как открыть

Дважды кликните `index.html`. Для локального сервера:

```powershell
python -m http.server 8080 --directory advokat-genrih
```

Сайт полностью статический: без сборки, внешних шрифтов и CDN. Шрифты —
системные (Bahnschrift, Georgia, Segoe UI), поэтому одинаково выглядит офлайн.
